# 🍆 Пиписьки

Лёгкий Discord-подобный сайт с голосовыми звонками и демонстрацией экрана.

**Название:** Пиписьки  
**Стиль:** Discord dark theme  
**Ресурсы:** минимальные (только сигналинг WebRTC + JSON-файл)

## Что умеет

- Регистрация и вход
- Смена аватара (загрузка картинки)
- Список онлайн-пользователей в реальном времени
- 1-на-1 голосовой звонок
- Демонстрация экрана
- Включение/выключение микрофона и камеры

## Деплой на Railway (рекомендуется)

1. Зайди на [railway.app](https://railway.app) и создай новый проект
2. Выбери **Deploy from GitHub** или **Empty project** → загрузи папку
3. Railway сам найдёт Dockerfile
4. (Опционально) добавь переменную:
   - `JWT_SECRET` = любой длинный секрет (например `my-super-secret-12345`)
5. Нажми Deploy

После деплоя получишь ссылку вида `https://pipiski-production.up.railway.app`

## Локальный запуск

```bash
npm install
npm start
```

Открой http://localhost:3000

## Как пользоваться

1. Зарегистрируй два аккаунта (в разных браузерах / инкогнито)
2. Оба появятся в списке «Онлайн»
3. Кликни на человека → начнётся звонок
4. Прими звонок
5. Кнопки: 🎤 микрофон, 📷 камера, 🖥️ экран, 📵 сброс

## Технические детали

- **Сервер:** Node.js + Express + Socket.io
- **Хранение:** простой `users.json` (почти ноль RAM)
- **Медиа:** чистый WebRTC P2P (сервер не трогает аудио/видео)
- **STUN:** Google public STUN-серверы
- Потребление: обычно < 50–80 МБ RAM даже при нескольких пользователях

## Важно

- Звонки работают только 1-на-1
- Оба пользователя должны быть онлайн
- Для демонстрации экрана браузер попросит разрешение
- На мобильных некоторые функции (screen share) могут быть ограничены

Сделано специально лёгким, чтобы Railway (даже free/hobby) тянул без проблем.
